# Frame and input interaction blueprint

## Purpose and projection rules

BX-BP03 exposes staging, preparation, publication and input correlation across
prototype session, host and render worker. Include old-frame input while a new
frame prepares, failed/obsolete result, and publication with matching bindings.

The intended static projection is a Mermaid sequence diagram. A later executable
scenario uses a separately specified scenario language, not automatic execution
of Mermaid arrows. Show simulated participants and missing behavior explicitly.

Assertions about outcomes originate in requirements/contracts, not an
unconditional scripted success. Record event/frame identity and ordering evidence.
